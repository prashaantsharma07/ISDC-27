TeamMARS-PID-tuner(DRONE) 5.1.1 — Linux (x86_64)
=================================================

Needs: Ubuntu 24.04 or newer (or another recent 64-bit Linux).

1. Copy TeamMARS-PID-tuner_5.1.1_x86_64.AppImage anywhere (e.g. your home folder).
2. Right-click it -> Properties -> Permissions -> tick "Allow executing file as program"
   (or in a terminal:  chmod +x TeamMARS-PID-tuner_5.1.1_x86_64.AppImage )
3. Double-click it.

If it says "Cannot mount AppImage / FUSE":   sudo apt install libfuse2t64
If the drone's USB port is "busy": close QGroundControl / Mission Planner first —
only one program can use the flight controller at a time.

Safety: the app changes nothing on the drone until you press "Upload".
It backs up parameters before each step.

Check the file is not corrupted (optional):
  sha256sum -c TeamMARS-PID-tuner_5.1.1_x86_64.AppImage.sha256

Based on ArduPilot Methodic Configurator (GPL-3.0). Source code is available from the TeamMARS team on request.
